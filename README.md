# 만성질환 처방시장 대시보드

고혈압, 이상지질혈증, 당뇨 8개 성분(텔미사르탄, 로사르탄, 암로디핀, 아토르바스타틴, 로수바스타틴, 시타글립틴, 글리메피리드, 메트포르민)의 2024~2025년 처방시장 규모와 추이를 보는 제약 마케터용 대시보드입니다.

- 질환군(전체, 고혈압, 이상지질혈증, 당뇨)과 지표(처방금액, 처방 환자수, 처방건수) 필터
- 2025년 연간 지표와 전년 대비 증감, 월별 추이, 성분별 분기 추이, 권역별 처방금액, 성분별 점유율 표

## 데이터

오즈코딩스쿨 AI 헬스케어 SQL 실습 데이터(`kr_claims`)의 가상 청구자료를 집계했습니다. 실제 진료 기록이나 실제 시장 규모가 아닙니다.
집계 결과는 `data/*.json` 에 있습니다.

## 구조

- `src/page.html`: 대시보드 본문(차트와 표)
- `data/*.json`: 집계 데이터
- `build.py`: 두 가지를 합쳐 `index.html` 을 만듭니다 (`python3 build.py`)
